# zeroln.com

The public website of SIA "ZeroLN": the company home page, the products page and the RangeDot product pages (the product page, the privacy policy, the Terms of Use and the support page under `products/RangeDot/`). The root folders `privacy/`, `terms/` and `support/` redirect to the product paths.

The files are generated. Do not edit them here. The source is `tools/site_build.py` in the private manager folder
(`store/privacy-policy.md`, `store/terms.md`, `store/support-page.md`). Run the tool, then copy `store/site/` into this repository.

Hosting: GitHub Pages, branch `main`, folder `/ (root)`, custom domain `zeroln.com` (see `CNAME`).
