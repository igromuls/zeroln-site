# zeroln.com

The public website of SIA "ZeroLN": the company home page and the RangeDot privacy policy and support page.

The files are generated. Do not edit them here. The source is `tools/site_build.py` in the private manager folder
(`store/privacy-policy.md`, `store/support-page.md`). Run the tool, then copy `store/site/` into this repository.

Hosting: GitHub Pages, branch `main`, folder `/ (root)`, custom domain `zeroln.com` (see `CNAME`).
